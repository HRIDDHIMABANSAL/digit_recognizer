# digit_recognizer
This project implements a two-layer neural network from scratch using NumPy to recognize handwritten digits (0–9) from 28 × 28 grayscale images.

Technologies Used: Python, NumPy, Pandas, Matplotlib, Neural Networks, ReLU, Softmax, Backpropagation, Gradient Descent, One-Hot Encoding

Dataset: The Kaggle Digit Recognizer dataset contains 42,000 labeled training images and 28,000 test images. Each image consists of 784 pixel values.

Dataset Link: https://www.kaggle.com/competitions/digit-recognizer

The dataset is not included in this repository due to its large size.

The neural network consists of an input layer with 784 neurons, a hidden layer with 10 neurons using ReLU activation, and an output layer with 10 neurons using Softmax activation. The model uses one-hot encoding, forward propagation, backpropagation, and gradient descent for training.

Development Set Accuracy: 89.18%
Training Iterations: 1,500
Learning Rate: 0.10
